⚡ Bionic-Style Reader — Bookmarklet

No Developer mode. No "Load unpacked". No settings menus. Easy install.

👇 Drag this button directly into your Chrome Bookmarks Bar:
⚡ Bionic Read
  1. Show your Chrome Bookmarks bar if it's hidden: press Cmd + Shift + B (Mac) or Ctrl + Shift + B (Windows).
  2. Drag the purple "⚡ Bionic Read" button up into your bookmarks bar.
  3. Now, on any website (Medium, Notion, Wikipedia, news, blogs), just click "⚡ Bionic Read" in your bookmarks bar.
  4. Click it again anytime to toggle back to normal!

Interactive Test Area

Try clicking the button above or dragging it to your bookmarks bar and clicking it. Notice how the reading anchors highlight the beginning of words to help guide your eyes and maintain focus while reading long texts.

Note for GitHub users: When viewing this page directly on GitHub, drag-and-drop does not work because GitHub renders HTML files as raw source code. To use the bookmarklet, open bookmarklet.html locally in your browser (Cmd+O) or host it via GitHub Pages.
