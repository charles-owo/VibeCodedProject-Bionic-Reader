# ⚡ VibeCodedProject — Bionic Reader

> High-contrast Bionic Reading Chrome Extension for faster reading, focus guidance, and superior dark-mode typography.

## 📦 Projects

- [**bionic-reader/**](./bionic-reader) — Manifest V3 Chrome Extension with theme-aware high contrast, anchor color highlighting, dynamic infinite scroll support, and custom saccade controls.

---

### Quick Start
1. Go to `chrome://extensions` in Google Chrome.
2. Enable **Developer mode** (top-right).
3. Click **Load unpacked** and select the [`bionic-reader`](./bionic-reader) folder.
4. Open [`bionic-reader/test.html`](./bionic-reader/test.html) or any webpage and press <kbd>Alt</kbd> + <kbd>B</kbd> to toggle!
